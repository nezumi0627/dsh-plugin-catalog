# DSH Plugin Catalog

Shareable DSH plugin tarballs. Each tarball was scanned for credential-like files and content before publication.

## Install a plugin

Use `dsh-plugin-share` to inspect the tarball first. Give it the download URL and the matching SHA-256 below, review the plugin and its dependencies, then approve installation.

```text
Use plugin-share to inspect this tarball, then install it after I approve:
URL: <paste the plugin download URL>
SHA-256: <paste the matching digest>
Show me the plugin name, author, digest, and dependencies before installing.
```
